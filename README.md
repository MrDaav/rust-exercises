# Rust Exercises

A collection of programming challenges and exercises completed while learning Rust.

The goal of this repository is to practice problem-solving, strengthen programming fundamentals, and document my progress with Rust.

## Exercises

| # | Exercise | Description | Concepts |
|---|---|---|---|
| 1 | [El Mensaje Simétrico del Espacio](./1-Palindromo/) | Check whether a string is a palindrome. | Strings, iterators, functions, standard input |

## Getting Started

Each exercise is organized in its own directory and may contain an independent Cargo project.

To run an exercise:

```bash
cd 1-Palindromo
cargo run
```

You need to have [Rust](https://www.rust-lang.org/tools/install) and Cargo installed.

## Learning Goals

- Practice Rust syntax and core concepts.
- Improve problem-solving skills.
- Learn to work with strings, collections, and iterators.
- Become comfortable with Cargo, Git, and GitHub.
- Document solutions and lessons learned.
