# Reto #1 — El Mensaje Simétrico del Espacio

Solución en Rust del reto de programación de [MexicoDev](https://mexicodev.org/es/retos/1).

## Objetivo

Determinar si una cadena es un palíndromo, ignorando los espacios en blanco y las diferencias entre mayúsculas y minúsculas.

## Conceptos practicados

- Lectura de entrada estándar con `std::io`.
- Funciones y valores booleanos.
- Procesamiento de cadenas e iteradores.
- Uso de `filter`, `map`, `collect`, `rev` y `eq`.

## Ejecutar

Requiere Rust y Cargo.

```bash
cargo run
```
